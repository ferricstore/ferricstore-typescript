    Class FerricStoreStore

    LangGraph.js long-term memory store backed by FerricStore.

    It implements hierarchical namespaces, exact/comparison filters, ordered pagination, batching, CAS-protected item commits, and append-only discovery indexes. Vector search is deliberately rejected until a semantic index is configured rather than silently returning an unranked result.
